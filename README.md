# Habit Flow - Advanced Habit Tracking Dashboard

![Habit Flow Banner](https://images.unsplash.com/photo-1484480974693-6ca0a78fb36b?auto=format&fit=crop&q=80&w=2072)

**Habit Flow** is a production-grade, privacy-focused habit tracking application built for performance and user experience. It combines powerful analytics, gamification, and smart insights to help you build and maintain positive habits.

## 🚀 Key Features

### 📊 Advanced Analytics Suite
- **Consistency Heatmap**: GitHub-style visualization of your daily activity.
- **Mental State Correlation**: Discover how your journaling habits affect your productivity.
- **Weekly Trends**: Bar charts showing your completion rates over time.
- **Interactive Insights**: Click "i" buttons on charts to learn how to interpret your data.

### 🎮 Gamification & Social
- **Badges & Achievements**: Earn badges like "Week Warrior" and "On Fire" for your streaks.
- **Leaderboards**: Compete with friends or globally.
- **Streaks**: Track your current and best streaks with visual flame indicators 🔥.

### 🛡️ Privacy & Security
- **Private Logging**: All user activity is securely synced to a private Firestore collection.
- **Local First**: Data is persisted locally for instant load times.
- **Secure Auth**: Google Authentication via Firebase.

### 🧠 Smart Features
- **Habit Strength**: Visual meter showing the robustness of your habits (0-100%).
- **Flexible Schedules**: Support for Daily, Weekly, and Interval-based habits.
- **Smart Insights**: Local pattern detection to offer personalized tips.

## 🛠️ Tech Stack

- **Frontend**: React, TypeScript, Vite
- **Styling**: Tailwind CSS, Framer Motion (Animations)
- **State Management**: Zustand (with Persistence)
- **Backend/Auth**: Firebase (Auth, Firestore, Analytics)
- **Charts**: Recharts
- **Icons**: Lucide React

## ⚡ Getting Started

1.  **Clone the repository**
    ```bash
    git clone https://github.com/arvin95/habit_tracker.git
    cd habit_tracker
    ```

2.  **Install dependencies**
    ```bash
    npm install
    ```

3.  **Run the development server**
    ```bash
    npm run dev
    ```

4.  **Build for production**
    ```bash
    npm run build
    ```
